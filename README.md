# 🎙️ TeamSpeak 3 Enterprise Server Suite (Ubuntu Linux)

یک سامانه جامع، فوق‌العاده پایدار و حرفه‌ای برای راه‌اندازی، مدیریت و مانیتورینگ ۲۴/۷ سرور **تیم اسپیک ۳ (TeamSpeak 3)** بر روی توزیع‌های لینوکس اوبونتو (**Ubuntu 20.04 / 22.04 / 24.04 LTS**).

این سیستم به طور اختصاصی طراحی شده تا سرور شما تحت هیچ شرایطی آفلاین نماند (**High Availability & Auto-Healing**) و تمام نیازهای یک مدیر سرور حرفه‌ای را برطرف سازد.

---

## 🌟 ویژگی‌های کلیدی سیستم

- **🛡️ راه‌اندازی و نگهداری خودکار ۲۴/۷ (Auto-Healing Watchdog):**
  - مانیتورینگ چندلایه‌ای سلامت سرور (بررسی وضعیت Systemd، پردازش هسته `ts3server`، پورت صوتی ۹۹۸۷ و پورت کوئری).
  - در صورت بروز هرگونه کرش، قفل شدن (Freeze) یا پر شدن غیرعادی رم، سرور در کمتر از ۳ ثانیه به صورت خودکار ری‌استارت و احیا می‌شود.
  - سیستم ضد حلقه (Anti-Crash Loop) برای جلوگیری از بار اضافی در صورت مشکلات بنیادین.

- **⚡ ایزوله‌سازی و امنیت سخت‌گیرانه (Systemd Hardening):**
  - اجرای سرور در قالب یوزر سیستمی غیر روت و محدود (`teamspeak`).
  - فعال‌سازی ساندباکسینگ لینوکسی (`ProtectSystem=full`، `ProtectHome=true`، `NoNewPrivileges=true`، `PrivateTmp=true`).
  - ارتقای اولویت پردازش صدا (`Nice=-5`) جهت تضمین کمترین پینگ و عدم افت پکت (Zero Packet Loss).

- **🎛️ کنترل پنل خط فرمان پیشرفته (`ts3ctl`):**
  - محیط گرافیکی متنی (TUI) زیبا به همراه منوی تعاملی و رنگی.
  - مشاهده زنده وضعیت مصرف CPU، رم، زمان روشن بودن (Uptime)، اتصالات پورت‌ها و لاگ‌ها.
  - استخراج خودکار توکن اولیه ادمین (`Privilege Key`).

- **💾 سیستم بک‌آپ‌گیری هوشمند (Hot-Backup & Safe Restore):**
  - تهیه نسخه پشتیبان از دیتابیس بدون قطع کردن فعالیت کاربران (`SQLite Hot Backup`).
  - ذخیره فایل‌های کانال‌ها، پرمیشن‌ها، لایسنس و کانفیگ‌ها در قالب فایل‌های فشرده `.tar.gz` دارای چک‌سام SHA256.
  - بک‌آپ‌گیری خودکار روزانه رأس ساعت ۴ صبح به همراه اعمال سیاست حذف خودکار بک‌آپ‌های قدیمی‌تر از ۱۴ روز.
  - ریستور کردن سرور تنها با یک دستور ساده.

- **🔄 آپدیتور خودکار و بدون ریسک (Zero-Downtime Updater):**
  - بررسی هوشمند آخرین نسخه منتشر شده در CDN رسمی تیم اسپیک.
  - تهیه بک‌آپ ایمن خودکار پیش از اعمال آپدیت و جایگزینی فایل‌های باینری بدون آسیب به دیتابیس و پرمیشن‌ها.

- **📢 سیستم اطلاع‌رسانی فوری (Discord & Telegram Webhooks):**
  - ارسال اعلان‌های گرافیکی رنگی به کانال دیسکورد یا ربات تلگرام هنگام روشن شدن، کرش، احیا خودکار، آپدیت یا تهیه بک‌آپ.

- **🔥 پیکربندی خودکار فایروال (UFW):**
  - باز کردن خودکار پورت‌های Voice (9987 UDP)، File Transfer (30033 TCP) و ServerQuery (10011 TCP).

## 🚀 نصب سریع با یک کلیک (Quick Start)

روی سرور اوبونتو خود، دستورات زیر را اجرا کنید:

```bash
# ۱. وارد پوشه پروژه شوید
cd "TS-sv"

# ۲. دسترسی اجرایی به اسکریپت نصب بدهید
chmod +x install.sh

# ۳. اسکریپت نصب خودکار را اجرا کنید
sudo bash install.sh
```

## 💻 دستورات مدیریت سرور (`ts3ctl`)

پس از نصب، دستور `ts3ctl` در تمام محیط‌های ترمینال لینوکس شما در دسترس است:

```bash
ts3ctl                 # باز کردن منوی تعاملی و زیبا برای تمام عملیات
ts3ctl status          # نمایش داشبورد جامع وضعیت سرور، پورت‌ها و منابع
ts3ctl start           # روشن کردن سرور و سیستم مانیتورینگ
ts3ctl stop            # خاموش کردن سرور
ts3ctl restart         # راه‌اندازی مجدد ایمن
ts3ctl token           # بازیابی توکن دسترسی اولیه ServerAdmin
ts3ctl logs            # مشاهده آنلاین لاگ‌های زنده سرور
ts3ctl backup          # گرفتن یک نسخه پشتیبان فوری
ts3ctl backups         # لیست کردن تمام فایل‌های بک‌آپ موجود
ts3ctl restore <file>  # بازیابی سرور از یک فایل بک‌آپ
ts3ctl check-update    # بررسی وجود آپدیت جدید برای تیم اسپیک
ts3ctl update          # آپدیت خودکار به آخرین نسخه بدون حذف اطلاعات
ts3ctl watchdog status # مشاهده وضعیت و آخرین گزارش‌های سیستم خودترمیمی
ts3ctl firewall        # اعمال مجدد تنظیمات فایروال UFW
ts3ctl query           # اتصال خط فرمان به پنل ServerQuery
```
